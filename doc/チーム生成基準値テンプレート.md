# チーム生成基準値テンプレート

## 目的

チームエディタで、全能力の平均値を保ったまま特徴のある初期チームを作る。数値に詳しくない利用者は能力ランクを、細かく指定したい利用者は数値を使う。

## 入力方式

| 方式 | 入力 | 内部値 |
|---|---|---|
| 数値入力 | 0〜5500 | 入力値をそのまま平均目標にする |
| ランク入力 | S〜E- | ランク帯域の中央値を平均目標にする |

| ランク | 平均目標 |
|---|---:|
| S | 5250 |
| A+ | 4750 |
| A- | 4250 |
| B+ | 3750 |
| B- | 3250 |
| C+ | 2750 |
| C- | 2250 |
| D+ | 1750 |
| D | 1250 |
| E+ | 750 |
| E- | 250 |

## チーム補正

補正は能力値を単純加算してチーム全体を強くするものではない。設定された分野補正を全能力数で重み付けして中央化し、強い分野と弱い分野へ能力予算を再配分する。生成後にも全選手・全能力の平均を基準値へ戻すため、基準値2750のフィジカル型は全体平均2750のままフィジカルが高く、テクニックが低くなる。

誤差の「小・中・大」は各能力と各選手のばらつきだけを変更し、最終的な全体平均は変更しない。

## 編集可能データ

`teameditor_templete/editor_options.json`の次の配列を起動時に読む。

| キー | 役割 |
|---|---|
| `generation_categories` | 補正対象となる能力分野と日本語能力キーの一覧 |
| `generation_profiles` | 表示名、説明、分野ごとの増減値 |

新しい補正は`generation_profiles`へ追加する。`modifiers`の正数は相対的に強く、負数は相対的に弱くする。未指定分野は0として扱う。存在しない分野IDと数値でない補正値は無視し、設定ファイルが古い場合はバランス型へフォールバックする。

## 処理の分離

ランク変換と分野別目標計算は`scripts/team/team_template_profile.py`、チームJSON生成は`scripts/team/team_editor_data.py`、表示と入力は`scripts/team/team_editor.py`が担当する。生成済みJSONには計算後の能力値だけを保存するため、試合エンジンと既存チームの読込仕様は変わらない。
