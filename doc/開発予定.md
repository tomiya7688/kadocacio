# この文書について

kadoka questにて開発予定のものをまとめる 
AIは設計を軽く書いても良いが深い設計については各自機能説明書.mdを作成して記入すること
表はmdの表機能を利用し、図はmermaidを使用する
実装が完了したら項目を削除すること
優先度について 緊急性が高いものは優先度が高く書かれる、尚、デフォルトは0とする
変更履歴:doc\ver.md
AI用メモ:AGENTS.md
仕様書:docs\FORMATS.md,AGENTS.md,README.md

共通コーディングルール
1クラスにつき1ファイル
1クラスは1つの責務を持つ
1関数につき1処理
処理系と画面系,データ系の分離
なにかあたらしいものを追加したときには(機能単位)githubへアップロード、git管理する
定期的なコミット、githubアップロード
ブランチは作業開始時に分けて終了してテストできたらそれをメインにする

#　ロジックの整理
各アプリは独立しておりそれぞれがコマンドによって動作を決定する
よってアプリ間の通信はコマンドによって行われる
例えば対戦画面の　画面　計算　学習　推論　データ読み込み　は当然別アプリである
また戦闘時とモンスター編成画面、マップ移動画面はそれぞれ別のアプリであり、それぞれがデータ層、UI層、処理層を持つ
