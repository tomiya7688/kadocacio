# クラス一覧

| クラス | 役割 |
|---|---|
| `KadocalcioBootstrap` (Godot) | 移行中の動作確認画面を表示し、終了操作を受け付ける。 |
| `run_tests.gd` のSceneTree (Godot) | 実エンジン上で起動基盤の検証を行い、結果を終了コードへ反映する。 |
| `Game` | アプリケーションの画面遷移、入力受付、ゲームループを統括する。 |
| `GpuPresenter` | SDL2 GPUレンダラーへ完成済み画面を転送する。 |
| `RendererMixin` | メインメニューと試合画面を描画する。 |
| `MainMenuView` | 開始メニューのカード配置、見た目、フォーカス表示を描画する。 |
| `TeamSelectView` | 単体試合の対戦チーム、配置プレビュー、会場と開始操作を描画する。 |
| `MatchHudView` | 試合中のスコア、勝敗予想、統計、ログと観戦操作を表示する。 |
| `PlayerStatusView` | 両チームのピッチ上選手の現在状態、スタミナと能力ランクを表示する。 |
| `OtherMatchesView` | 各会場の最新スコアと独立した時計を、全件閲覧可能な速報グリッドへ表示する。 |
| `SettingsView` | 共通設定の表示とマウス・キーボードのフォーカスを、同じコントロール配置で扱う。 |
| `FulltimeView` | 試合終了後のスコア、統計、得点・同日結果のページと次の操作を表示する。 |
| `FulltimePagination` | 終了後の記録ページを範囲内に保ち、試合変更時に初期化する。 |
| `LeagueRendererMixin` | リーグ戦の編集、日程、成績、進行画面を描画する。 |
| `LeagueAutoProgressConfig` | リーグ自動進行の観戦方法と進行速度を保持する。 |
| `LeagueSimulationSession` | 複数の裏試合ワーカーの開始、進捗収集、終了を管理する。 |
| `LeagueManager` | リーグ定義、日程、順位、セーブデータを管理する。 |
| `WindowsMemoryStatus` | Windowsから利用可能メモリを取得する構造を表す。 |
| `Player` | 一人の選手の能力、位置、スタミナ、コマンド状態を保持する。 |
| `Team` | 一チームの選手構成、戦術、試合成績を保持する。 |
| `Ball` | ボールの位置、速度、所有者、飛行状態を保持する。 |
| `Match` | 一試合の固定ステップ進行とサッカー判定を統括する。 |
| `MatchResult` | 試合終了後の得点・統計・得点者を変更不能な値として保持する。 |
| `MatchStatusSnapshot` | 試合中のスコアボードに必要な時点状態を変更不能な値として保持する。 |
| `MatchLogEvent` | 試合ログ一件の発生順・二つの時計・メッセージを変更不能な値として保持する。 |
| `PendingKick` | キックモーションから接触までの保留情報を保持する。 |
| `PassRoute` | パス候補の到達地点と危険度評価を保持する。 |
| `PlayerCommand` | 選手AIが選択できる行動を列挙する。 |
| `CommandSpec` | 一コマンドの優先度と拘束時間を保持する。 |
| `ManagerProfile` | 監督AIが判断に使う能力値を保持する。 |
| `TeamForecast` | 勝敗予想に使う一チーム分の評価値を保持する。 |
| `TrapStyle` | トラップに使う身体部位を列挙する。 |
| `PerformanceSettings` | CPU、GPU、裏試合品質のユーザー設定を保持する。 |
| `CpuUsageLimiter` | 一ワーカープロセスのCPU使用時間を協調的に制限する。 |
| `StepMatch` | 固定ステップ実行器が必要とする試合インターフェースを定義する。 |
| `RealtimeSimulationDriver` | 描画あり試合へ実時間分の固定ステップを供給する。 |
| `SimulationLimits` | ヘッドレス試合の終了条件とCPU予算を保持する。 |
| `TeamTelemetry` | 一チーム分の行動、密集、奪取統計を集計する。 |
| `MatchTelemetry` | 試合判定を変えずに両チームの統計を観測する。 |
| `SimulationResult` | ヘッドレス試合の終了理由と到達状態を保持する。 |
| `TeamEditor` | チームJSONの作成、編集、検証、保存UIを管理する。 |
| `UniformEditor` | 5パーツのユニフォーム描画編集と読込・書出しUIを管理する。 |
| `EditorIssue` | チームJSON検証で見つかった一件の問題を表す。 |
| `TeamTunerSession` | 試合シミュレーションを使った能力配分探索を管理する。 |
| `NinetyMatchStressGame` | 表示一試合と裏試合群を同時実行して性能を計測する。 |
| `LeagueEvaluationRunner` | リーグの放置評価、試合日進行、ログ、チェックポイントを統括する。 |
| `Rule` | 静的解析で適用するアーキテクチャ境界ルールを保持する。 |
| `Violation` | アーキテクチャ境界違反の検出結果を保持する。 |
| `Check` | コミット前に実行する1件の静的チェック定義を保持する。 |
| `BranchCoverage` | ゲーム本体または開発者ツール群の分岐カバレッジ集計値を保持する。 |
| `Profile` | Kadocalcio向けUPD Commander静的解析の対象・ルール・失敗条件を保持する。 |
